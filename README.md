# Goodwill Revenue Forecasting

Data Engineering and Machine Learning portfolio project using:

- IRS Form 990 nonprofit data
- FRED economic indicators
- Python ETL
- PyTorch Linear Regression

## Project Goals

Forecast Goodwill revenue using economic and organizational factors.

## Technologies

- Python
- Pandas
- NumPy
- PyTorch
- FRED API

## Results

- Removed data leakage caused by Net Income
- Generated 3,000 synthetic observations for model stability
- Produced realistic revenue forecasts of approximately $70.5M
